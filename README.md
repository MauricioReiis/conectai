# Conectaí

Protótipo responsivo de uma plataforma para gestão de bots, campanhas, contatos e atendimento via WhatsApp.

## Primeira versão

- Login demonstrativo
- Painel operacional para clientes
- Painel administrativo
- Visão geral com indicadores e desempenho
- Navegação por conversas, bots, campanhas, contatos e relatórios
- Layout dedicado para desktop e navegação otimizada para mobile

## Executar localmente

```bash
npm install
npm run dev
```

Abra `http://localhost:5173` e utilize os dados já preenchidos na tela de login.

> Este protótipo usa dados demonstrativos. Autenticação real, banco de dados e integração com a API oficial do WhatsApp serão adicionados nas próximas etapas.
